# VEXIS TEAM — запуск и управление сайтом

## Запуск на Windows

1. Установите Node.js LTS: https://nodejs.org/
2. Распакуйте архив `VEXIS_SITE.zip`.
3. В основной папке лежат два файла: `1 - Запустить сайт.bat` открывает сайт, а `2 - Открыть админку.bat` открывает панель управления. Оба файла сами запускают сервер, если он ещё не запущен; при необходимости каждый выберет свободный порт.

Остальные файлы находятся во вложенной папке `VEXIS_APP`. Не перемещайте её отдельно от файлов запуска. Сервер можно запустить вручную командой `npm start` из папки `VEXIS_APP`.

## Что можно менять

В админ-панели можно добавлять, изменять и удалять игроков, новости, матчи, турниры и товары магазина. Профиль игрока включает национальность, роль, фотографию, показатели, историю матчей и результаты турниров. Для фотографии выберите PNG, JPG или WebP до 5 МБ.

Списки показателей и истории игрока заполняются по одному пункту на строку:

- Статистика: `название показателя | значение`
- Матч: `дата | соперник | счёт | результат`
- Турнир: `название турнира | место или результат | год`

Изменения сохраняются в `content.json`; загруженные фотографии помещаются в `assets`. Перед переносом проекта или передачей обновлённого сайта сохраните папку целиком. Исходные файлы сайта сами по себе не меняются — изменяемые данные лежат отдельно.

Сайт и панель управления доступны локально на этом компьютере. Не выставляйте текущую локальную админку напрямую в интернет: она не оснащена входом по паролю.

## GitHub и публикация в интернете

GitHub Pages размещает статические файлы и не запускает Node.js. Поэтому, если загрузить проект в GitHub Pages, админ-панель не сможет сохранять изменения на опубликованном сайте.

Чтобы менять публичный сайт через админку, нужен Node.js-хостинг для `server.js`, постоянное хранилище для данных и фотографий, и защищённая паролем админ-панель. GitHub можно использовать для хранения исходного кода и автоматической отправки обновлений на хостинг, но сам по себе GitHub репозиторий не даёт работающую онлайн-админку.
