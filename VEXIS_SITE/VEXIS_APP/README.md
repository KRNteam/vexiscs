# VEXIS TEAM — запуск и управление сайтом

## Запуск на Windows

1. Установите Node.js LTS: https://nodejs.org/
2. Распакуйте архив `VEXIS_SITE.zip`.
3. В основной папке лежат два файла: `1 - Запустить сайт.bat` открывает сайт, а `2 - Открыть админку.bat` открывает панель управления. При первом локальном запуске админки создайте пароль длиной не менее 12 символов и повторите его. Пароль вводится скрыто и не сохраняется в файлах. Пока сервер работает, вход в панель защищён этим паролем.

Остальные файлы находятся во вложенной папке `VEXIS_APP`. Не перемещайте её отдельно от файлов запуска. Сервер можно запустить вручную командой `npm start` из папки `VEXIS_APP`.

## Что можно менять

В админ-панели можно добавлять, изменять и удалять игроков, новости, матчи, турниры и товары магазина. Профиль игрока включает национальность, роль, фотографию, показатели, историю матчей и результаты турниров. Для фотографии выберите PNG, JPG или WebP до 5 МБ.

Списки показателей и истории игрока заполняются по одному пункту на строку:

- Статистика: `название показателя | значение`
- Матч: `дата | соперник | счёт | результат`
- Турнир: `название турнира | место или результат | год`

Изменения сохраняются в `content.json`; загруженные фотографии помещаются в `assets`. Перед переносом проекта или передачей обновлённого сайта сохраните папку целиком. Исходные файлы сайта сами по себе не меняются — изменяемые данные лежат отдельно.

Для входа в админку используется парольная сессия; выход из панели завершает её. Пароль должен содержать не менее 12 символов. Без настроенного пароля изменения через API запрещены.

## GitHub и публикация в интернете

GitHub Pages размещает статические файлы и не запускает Node.js. Поэтому, если загрузить проект в GitHub Pages, админ-панель не сможет сохранять изменения на опубликованном сайте.

Чтобы менять публичный сайт через админку, нужен Node.js-хостинг для `server.js` и постоянное хранилище для данных и фотографий. Для Render задайте пароль отдельно в настройках сервиса:

1. Откройте сервис Render → **Environment**.
2. Добавьте переменную `ADMIN_PASSWORD` и задайте ей свой пароль длиной не менее 12 символов.
3. Сохраните изменения и дождитесь перезапуска сервиса.

Не записывайте пароль в GitHub, исходники или ZIP-архив. При отсутствии `ADMIN_PASSWORD` онлайн-вход отключён, а публичная часть сайта продолжает работать. Админ-панель использует защищённую сессию с ограниченным сроком действия; после перезапуска сервера нужно войти снова. GitHub можно использовать для хранения исходного кода и автоматической отправки обновлений на хостинг, но сам по себе GitHub репозиторий не даёт работающую онлайн-админку.
